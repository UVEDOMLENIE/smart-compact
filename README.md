# smart-compact

Мод для Claude Code. Сжимает толстый чат вовремя и так, что важное не теряется. Показывает, сколько стоит каждый ответ.

## Что делает

Над полем ввода справа, рядом с кнопками самого поля, — цветная точка, кнопка «237 тыс. · сжать» и «◨», она открывает панель. Слева — цена последних ответов.

```
▂▃▂▅▃▇▂▃▄▂▃▄  ответ ≈0,048% недели      ● [237 тыс. · сжать] [◨]
```

Цвет точки говорит, что будет дальше:
- **зелёный**, до 200 тыс. — сжимать нечего, авто чат не трогает;
- **жёлтый**, 200–400 тыс. — авто сожмёт его на ближайшей паузе;
- **красный**, от 400 тыс. — каждый ответ перечитывает весь чат, сжать стоит сразу. Кнопка тогда выделена.

В чате с маленьким окном цвет считается от заполнения: с 50% жёлтый, с 80% красный.

Нажал кнопку:
1. Чат сам пишет **сохранёнку**: что сейчас в работе, где файлы, что обещано.
2. Мод запускает `/compact`.
3. После сжатия сохранёнка возвращается в чат слово в слово.

**Авто.** Если чат толще 200 тыс. и после его ответа 47 минут тихо, он сжимается сам, тоже с сохранёнкой. Вечером ушёл — утром толстые чаты уже сжаты.

**Цена ответа.** Слева на полосе — столбики последних 12 ответов, правый — последний. Высота пропорциональна цене: самый дорогой из 12 — во всю высоту, остальные против него. В Desktop столбики — картинки, одной ширины, на одной линии. Рядом цена последнего: `ответ ≈0,048% недели`. Пока ответ идёт, правый столбик растёт с каждым запросом модели, подпись — «идёт ответ ≈…». Наведи мышь на столбик — всплывёт цена именно этого ответа. И под каждым ответом в переписке — бледная строка: `≈0,048% недели · чат +12 тыс.`. Её рисует только экран, в память чата она не попадает. Считается бесплатно, из того, что Claude Code уже знает о ходе, вместе с агентами. В панели — итог за чат и сколько ещё тёплый кэш.

Счётчик лимита в самом Claude обычно больше: подписку тратят и другие чаты, и облако, а мод считает только этот чат.

## Почему это работает

- **Сжатие теряет детали.** `/compact` заменяет разговор коротким пересказом. Сохранёнку чат пишет себе сам, пока ещё всё помнит, и она приходит обратно целиком.
- **Кэш живёт час.** Claude Code держит чат в кэше час от последнего вызова модели. Сжатие в пределах часа читает чат из кэша, это быстро и дёшево. После часа первый ход перечитывает весь чат по полной цене. Поэтому сжимать надо до того, как кэш остынет. Холодные чаты мод не трогает: это дороже, чем оставить их как есть.
- **Почему 47 минут.** Сохранёнка и сжатие вместе идут 3–4 минуты. Они должны закончиться раньше, чем Claude Code сожмёт чат сам, без сохранёнки (~54-я минута), и раньше, чем остынет кэш (60-я).
- **Почему 200 тыс.** Около 90 тыс. в любом чате — обвязка: инструкции и инструменты. Её сжатие не трогает. От 200 тыс. сжатие окупается, ниже выгода около нуля.
- **Только в тишине.** Любой ход чата, инструмент или твоё сообщение сбрасывает таймер. Пока работает агент, мод не жмёт. Написал в чат, пока готовится сжатие, — оно отменится.

## Поставить

Нужен Claude Code с модами, проверено на 2.1.321. Две команды в терминале:

```bash
claude plugin marketplace add UVEDOMLENIE/smart-compact
claude plugin install smart-compact@smart-compact
```

Вместо `UVEDOMLENIE/smart-compact` можно дать путь к скачанной папке этого репо.

Если установщик скажет, что настройки не заданы, — это нормально: работают умолчания. Новые чаты получат мод сразу. В уже открытом чате набери `/reload-plugins` или перезапусти приложение.

**Проценты недели посчитаны для плана Max за $200.** Если у тебя другой план, в `/config` поставь свою «Неделю подписки» или 0. При 0 цена ответа будет в ХТ, без процентов.

## Панель «◨»

Карточки в рамках: сверху — состояние словом или цветом, ниже — как работает, стрелками, внизу — кнопка. Чтобы понять мод, README читать не нужно.

```
╭ 237 тыс. из 1000 тыс. ──────╮
│ ██████████░░░░░░░░░░         │
│ жёлтый: 200–400 тыс. — …     │
╰──────────────────────────────╯
╭ Авто ● вкл ──────────────────╮
│ 200 тыс. → 47 мин тишины →   │
│ сжатие с сохранёнкой         │
│ [Выключить авто в этом чате] │
╰──────────────────────────────╯
```

- **размер**: число цветом, шкала зелёный / жёлтый / красный до 500 тыс., итог за чат и сколько ещё тёплый кэш;
- **авто**: вкл или выкл, как работает; когда идёт таймер — «сожмётся в 15:34, если чат будет молчать»; кнопка для этого чата;
- **сохранёнка**: короткая (около 1500 знаков) или подробная (до 5000: все числа, пути, номера; дороже на ≈0,015% недели); кнопка для этого чата;
- **цена ответа**: последние столбики, что они значат; кнопка скрыть / показать.

Почему авто в прошлый раз не сжало, пишет `/smart-compact`.

## Настроить

`/config` → раздел `smart-compact`. Всё уже настроено, менять не обязательно.

| Настройка | Умолчание | Что значит |
|---|---|---|
| Авто-сжатие | вкл | сжимать самому |
| Порог | 200 000 | авто — только от этого размера |
| Тишина | 47 мин | сколько ждать после ответа чата |
| Не чаще | 60 мин | пауза между авто-сжатиями |
| Не больше | 2 за 6 ч | предел авто на один чат |
| Сохранёнка | обычный | обычный (короткая) или расширенный (подробная) |
| Цена ответа | вкл | столбики на полосе и итог в панели |
| Неделя подписки | 1,2 млрд ХТ | для процентов. ХТ — цена одного входного токена Haiku. 0 — без процентов |
| Возвращать сохранёнку | вкл | выключи, только если это уже делает твой хук |
| Слово, от какого чата, папка-ящик | выкл | сжать чат по просьбе другого чата (ниже) |

## Выключить

- **В одном чате:** панель «◨» — переключатели авто и цены. Или `/smart-compact auto off`.
- **Везде:** `claude plugin disable smart-compact@smart-compact`.
- **Убрать совсем:** `claude plugin uninstall smart-compact@smart-compact`.

## Для тех, у кого много чатов

Один чат может попросить другой сжаться.

- **Сообщением.** В настройках укажи номер сессии чата-распорядителя (`squeezeFrom`). Его сообщение, в котором только слово `сожмись`, мод заберёт себе и сожмёт чат. Слово меняется (`squeezeWord`).
- **Файлом.** Укажи папку (`mailbox`). Положи туда файл `<первые 8 знаков номера сессии>.txt`, первой строкой `сожмись`. Мод проверяет папку раз в минуту и пишет ответ в тот же файл.

Если сжимали меньше 15 минут назад, такая просьба не выполняется.

## Откуда фичи

Часть фич пришла из наших экспериментальных модов («лаба»). Там фичи появляются и исчезают, поэтому здесь записано, из какого мода и какой версии взята каждая. ID — постоянные ID фич лабы.

| Фича здесь | Откуда | Как взята |
|---|---|---|
| Цена хода в ХТ и % недели (`ht`, `weekShare`) | `lab-turn-tokens` 0.0.2 (11.11.2026), LTT-F1 | формула и калибровка; цены моделей с тех пор свои, по справочнику Claude API |
| Ответ вместе с подагентами: их цена прибавляется к ответу, которому они принадлежат | `lab-turn-tokens` 0.0.2, LTT-F2 | как есть |
| Полоса над полем ввода: столбики цены слева, кнопки прижаты вправо (`justifyContent: space-between`, `width: 100%`) | `lab-turn-tokens` 0.0.2, вправо — 0.0.3, LTT-F4 | раскладка; столбики с 0.2.6 — свои картинки |
| Подсказка цены при наведении на столбик: отдельный интерактивный `Svg` на каждый столбик | `arena-a4` 0.0.5 (лаба), A4-F17 | способ; улучшено: подсказка на всю высоту колонки (`<title>` над прозрачной подложкой), чтобы низкий столбик было легко поймать |
| Цена под каждым ответом | идея — `lab-turn-tokens` 0.0.1, LTT-F3 | только идея: там `$.ui.place`, Desktop его не рисует. Здесь — перерисовка ответа (`AssistantMessage`), своё, 0.2.5 |

Своё, не из лабы: сжатие с сохранёнкой, авто, «сожмись», цвет и шкала, панель карточками, столбики-картинки (0.2.6; у лабы похожие — LTT-F8, 0.0.4, сделаны параллельно, код не брал).
